# Código de conduta

Este espaço reúne pessoas com diferentes experiências para ajudar a melhorar o Tripeiro. Trate todos com respeito, inclusive quando discordar.

- Foque no problema e em informações que ajudem a resolvê-lo; critique ideias sem atacar pessoas.
- Não publique assédio, ameaças, discriminação, insultos, spam ou divulgação de dados pessoais.
- Use exemplos fictícios e respeite a privacidade de quem aparece em textos e capturas.
- Evite repetir o mesmo relato em várias issues e mantenha os comentários relacionados à conversa.

O mantenedor pode moderar conteúdo, encerrar conversas ou restringir participação quando necessário para proteger este espaço. Essas decisões consideram a gravidade e o contexto da situação.

Para denunciar conteúdo ou comportamento inadequado, use os recursos de denúncia do GitHub disponíveis no comentário ou perfil. Não reproduza ofensas nem dados sensíveis em uma nova issue. Para vulnerabilidades do produto, use o [canal privado de segurança](SECURITY.md).
