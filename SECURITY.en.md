# Tripeiro security

[Português](SECURITY.md) | English

If you suspect a vulnerability or data exposure in Tripeiro, the skill or public distribution, use [Report a vulnerability](https://github.com/gdonscoi/tripeiro/security/advisories/new). This form sends a private report to the maintainer and requires a GitHub account.

**Do not publish vulnerability details in issues or Discussions.** For ordinary usage problems and suggestions, follow the [support guide](SUPPORT.en.md).

## What to report privately

- Affected product or component and version, if known.
- Environment and reproduction steps with fictional data.
- Observed behavior, possible impact and minimal evidence to help investigation.

Even in a private report, do not send passwords, tokens, documents, tickets, booking references, real reservations or a full trip export. If evidence depends on sensitive data, describe the situation and wait for guidance on sharing only what is necessary.

The maintainer reviews reports through the private channel and may request clarification. Any public disclosure should preserve personal data and allow preparation of a fix. There is no guaranteed response, fix or reward deadline.

Report the version where you observed the problem, even if it is not the latest. There is no public matrix of versions with guaranteed security maintenance yet; the affected version and fix are evaluated in the report.
